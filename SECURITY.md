# Security Policy

Please do not disclose a security vulnerability in a public issue.

Use [GitHub's private vulnerability reporting](https://github.com/Zaldaryon/WorldgenLib/security/advisories/new) when it is available. Include the affected WorldgenLib version, Vintage Story version, impact, reproduction steps, and any suggested mitigation. Remove secrets, player data, server addresses, and proprietary game files from reports.

If private reporting is unavailable, contact the maintainer through the [Zaldaryon GitHub profile](https://github.com/Zaldaryon) before making the issue public.

Supported versions and remediation timelines will be listed here once the first public source release is available.
