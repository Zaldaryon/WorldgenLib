# WorldgenLib API Reference

WorldgenLib is a server-side C# API for composing Vintage Story world-generation mods through ordered, additive hook points.

This site is generated from the public `WorldgenLib.VintageStory` project. The [API reference](xref:WorldgenLib.WorldgenLibAPI) lists the public types and members available to a mod. Low-level patch adapters are excluded from the reference.

## Start here

- [Consumer guide](xref:worldgenlib.consumer-guide) for registration and lifecycle basics.
- [Getting Started wiki page](https://github.com/Zaldaryon/WorldgenLib/wiki/Getting-Started) for the first integration.
- [Terrain hooks wiki page](https://github.com/Zaldaryon/WorldgenLib/wiki/Terrain-Hooks) for the terrain pipeline.
- [Map hooks wiki page](https://github.com/Zaldaryon/WorldgenLib/wiki/Map-Hooks) for region and map stages.

The [WorldgenLib Wiki](https://github.com/Zaldaryon/WorldgenLib/wiki) contains the conceptual guides. This site is the generated C# reference.
